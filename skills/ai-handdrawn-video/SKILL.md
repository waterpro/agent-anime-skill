# AI 手书与 PV 制作

把简报转成可追踪的镜头、角色、姿态、图层和验收记录，再生成和编排。画风可简化，角色身份、关键动作与用户指定保留的内容必须完整。

## 起点与本轮范围

- **从零制作**：沿用已有脚本、角色设定和获准音频；确定叙事段落与镜头节奏，再制作关键姿态、背景和动态样片。
- **参考 PV 改编**：主参考提供时间、动作、构图及指定视觉内容；角色参考提供人物身份。建立源帧到输出帧映射后替换约定元素。
- **现有工程返修**：将评论映射到镜头、帧区间和资产，只重开受影响部分及接缝；保留旧版和已通过素材。

先读最新简报、现有时间轴、素材登记和审核状态。记录输出规格、音频处理、必须保留的元素、修改范围、当前已获授权的工作与停止点。最新明确要求优先于历史方案；有冲突且会影响结果时才询问。

模型、工具及其能力如实记录，不声明不可用的固定版本。Python＋FFmpeg 是分层素材合成的可选默认；尊重用户已有工具选择，不把旧项目工具、角色数量、帧率或静音要求变成通用规定。

## 阶段总表

| 阶段 | 按此顺序做 | 主要产物 | 进入下一阶段的条件 |
| --- | --- | --- | --- |
| P0 素材与环境 | 登记用途/版本/授权；查工具、权限、空间；真实尺寸检查；小技术导出 | manifest、环境记录、技术测试 | 原件保留，可读取/生成/编码，测试明确不是美术样片 |
| P1 时间与内容 | probe → PTS/源帧 → 候选切点复核 → 音频/文字 → 输出映射 | meta、shots、timeline、beats、text cues、分镜 | 有效首尾明确；区间覆盖无误；候选与确切镜头区分；缺口列明 |
| P2 身份与画风 | 多参考核对 → 正侧背/服装映射 → 七维画风 → 典型试画 | identity、角色母版、style guide、测试图 | 同一角色可辨认，画风与设定同时通过 |
| P3-A 动态方法 | 选代表镜头 → 必要关键姿态 → 局部编排 → 导出对照 | 动态样片、实际帧、方法结论 | 重要动作、接触遮挡、比例、节奏与合成可行 |
| P3-B 逐镜头生产 | 读取镜头/母版 → 补必要姿态 → 分层 → 预览 → 冻结 | 镜头资产、姿态/图层清单、审核记录 | 所需动态覆盖，无缺图或占位回退 |
| P4 全片组装 | 统一帧函数 → 转场/文字/连续音轨 → 全片预览 | 镜头片段、全片预览、待改表 | 全部接缝及连续播放已检查，必改项解决 |
| P5 实片验收 | 导出 → probe/全解码 → 实际成片抽帧 → 版本绑定 | final、技术/美术报告、交付清单 | 文件有效，画面与批准素材一致，检查范围如实披露 |

这些是产物依赖，不是要求每阶段重新索要许可。已有授权覆盖后续阶段时继续推进；用户明确要求停在样稿、样片或标记修改完成处时，在该处交付暂停。

## 每个镜头的操作顺序

1. 读取已锁定的输出区间、参考证据、构图、节拍和文字，确认角色 ID 与服装 ID。
2. 加载当前已通过的角色母版和画风规范，列出本镜头必须发生的姿态/表情/接触变化。
3. 先做最难的变化：转身、手球交接、遮脸、近景比例或前后景交叉。查看完整头肩/半身与透明边缘。
4. 不同必要姿态补画，等价重复姿态复用。按参考节奏留帧；不要把“每次人物变动”扩成每视频帧重新生成。
5. 连接姿态、道具、相机与文字，查看局部首中末、动作极值和前后接缝；通过后冻结素材版本并扩展生产。
6. 最终从实际 MP4 提取同组证据，确认没有装入旧缓存、简化占位或原角色回退。

## 高代价返工的检查点

| 容易误判 | 实际检查与修法 |
| --- | --- |
| 粗线条等于丢弃细节 | 保留完整发型结构、发丝、脸眼、服装；几何占位只标草稿 |
| 球轨迹对齐就是动作对 | 同时对照肩肘腕手，区分蓄力/释放/飞行/接触/承重；静止低手加移动球仍不构成抛球 |
| 整张高清就是角色高清 | 检查原生尺寸和 alpha 主体像素；低清放大不能冒称原生高清 |
| 一种颜色可提取全部文字 | 文字与发衣背景可能同色，按真实层和局部遮挡构建遮罩 |
| 局部头部通过就是整段通过 | 复用身体/手球但检查真实头部 mask 外变化、比例极值、边界及最终成片 |
| 小补丁只看放大图 | 全画面查旧手/衣露出、道具切片、矩形硬边、颈部断接与取景 |
| 加 BT.709 标签就修好颜色 | 输入/输出像素约定必须一致；声明标签不执行颜色转换，raw RGB/YUV 都需明确约定 |
| 解码成功或误差小就是验收 | 技术、身份/画风、动作接触分别给证据，不能互相代替 |

## 收尾与分享

报告真实导出参数、实际查看的画面、连续播放范围、技术结果与未检查范围。完成本次标记和必要接缝后按约定暂停；用户要求立即暂停时，先停止自己启动的生成、渲染和编码，再做其他整理。

仅在明确授权的目标发布经验或成果。共享文本使用角色 A/B、相对路径与示例参数；按文件清单排除私有资产、聊天、账号、密钥、本机路径和可识别制作记录。保留既有版本，提交署名使用用户认可的公开身份或中性身份。
