# 角色、画风与动作

承接 [全流程示例](full-production-plan.md)：角色 A/B，镜头 s010/s020/s030。
角色数量、衣装和示例特征均可替换；先核对真实参考，不用示例填补未知设定。

## P2：多参考身份与服装

优先级按领域划分，而非把一张图设为所有问题的最高依据：

1. 最新用户指定的身份设定、必要特征和服装决定。
2. 已通过的角色母版；新材料冲突时列差异，确认是更新、光照还是旧稿。
3. 主视频提供动作/布局/时间和指定画风，不自动提供目标角色身份。
4. 辅助视频/画作只解决明确分配给它的风格问题，不取代主时间线。

角色 ID 和服装 ID 分开：同一角色换装不等于新角色，两位角色也不能只按衣服颜色分辨。
给每个镜头显式映射 sourceRole→characterId→outfitId；片尾背面、侧脸等需按发型/身形/设定核对。
未见的后背、下装、配饰结构不能凭空拼成新设计；不影响当前镜头时标未知，必需时确认或补参考。

角色档案最少记录：

| 项目 | 锁定内容 | 可观察证据 |
| --- | --- | --- |
| 体型 | 头身比、肩宽、身高关系、气质 | 同基线全身正/侧/背 |
| 头发 | 分缝、冠部体积、刘海、侧发、后发、发长/发色 | 完整头部与局部细节 |
| 面部 | 脸型、眉眼、瞳色、鼻嘴关系、年龄感 | 睁/闭眼、不同角度 |
| 服装 | 上下装剪裁、色块、领口、袖口、鞋袜 | 对应服装参考 |
| 配饰 | 佩戴侧、连接方式、前后遮挡 | 正/侧/背相互核对 |

把不可改项列为 hardConstraints，可风格化的线条/纹理列为 softConstraints。
先检查现有正/侧/背是否足够；缺哪种视角补哪种，不默认全部重画。
三视图统一身高、水平基线和尺度，分别保留独立图；不透明原图不是透明合成素材。


## 七维画风规范

| 维度 | 应写成可检查规则 |
| --- | --- |
| 线稿 | 外轮廓/内部线的粗细关系、断笔、双线、抖动幅度 |
| 脸部 | 眼睛比例、眉睫毛、鼻嘴简化、表情符号化方式 |
| 色彩 | 主背景/人物色域、饱和度、冷暖、明暗对比 |
| 上色 | 平涂、硬边阴影、柔和渐变等，按参考判断 |
| 纹理 | 纸感、颗粒、笔刷边缘与噪点是否静止/变化 |
| 运动 | 留帧、变形、速度线、残影、转场和节奏 |
| 构图 | 景别、留白、透视、窗口比例、重心和裁切 |

选择能显示关键差异的参考帧，把规则与图证放在 style guide。
先用典型镜头试画，同时比较角色身份与画风；冲突时先保住身份，再调整风格。
粗野线条、简练平涂也要保留冠部/刘海/侧发/发尾结构、细分发丝、脸眼和服装设定。
灰椭圆头、统一黑眼、少量外轮廓线只可作明确占位，不能因画风粗糙就冒充完整角色。

## P3-B：分镜驱动的关键姿态库

每镜头先列动作节点，再决定哪些已有姿态可以复用：

- 相同角度/表情/关键遮挡可复用已通过素材；仅平移缩放时检查尺度和相机关系。
- 头向、眼态、肩臂、手势、身体重心或接触关系改变时，补必要姿态或修正帧。
- 重要动作不能只移动整张立绘；小幅呼吸/相机运动可用分层变换。
- 留帧以该动作节奏为准，可 1/2/3 帧或更长 hold，不机械全片设“12 fps”。
- 生成记录保留真实工具/模型（可知时）、参考版本、提示词、种子（可用时）和资产版本。

姿态记录示例，alphaBox 为原图像素 `[left, top, right, bottom)`：

```json
{
  "poseId": "A-release-v1",
  "shotId": "s020",
  "characterId": "A",
  "outfitId": "A-casual",
  "identityVersion": "identity-v2",
  "image": "assets/shots/s020/A-release.png",
  "canvas": {"width": 1024, "height": 1024},
  "alphaBox": [112, 64, 912, 992],
  "targetSubjectSize": {"width": 400, "height": 464},
  "anchors": {"neck": [512, 280], "leftShoulder": [400, 320], "rightShoulder": [620, 320], "wrist": [760, 240]},
  "globalFrame": 72,
  "localFrame": 12,
  "contactState": "release",
  "reviewStatus": "example-pending"
}
```

画布 1024 不代表人物就有 1024 像素；检查非透明主体的 800×928 与目标 400×464。
记录缩放前后头高、肩宽及半身窗口，避免因透明留白不同导致同角色忽大忽小。
锚点坐标要注明空间：原图像素、裁切后像素或输出像素，变换后统一比较。

## 连贯的每镜头生成提示

将以下实例中的身份引用替换为已批准设定；不硬编码某个生成模型。
文字、背景、道具若由原片保留，提示词只生成需要替换的角色层。

| 镜头 | 正向提示实例 | 负向约束实例 |
| --- | --- | --- |
| s010 | 角色 A、A-casual，依据 identity-v2；正面半身、平静表情、完整头肩；参考指定粗细变化线条与平涂；透明背景，构图按源 s010 | 不改发型/瞳色/衣装；不新增字幕和背景；不截发顶/肩部；不生成原参考人物 |
| s020 | 角色 A 释放球的独立姿态，肩肘腕与源关键姿态一致；手指由握持到张开，完整发型脸眼；透明层；B 的接球姿态另绘，保持双方既定身高关系 | 不用静止低手配移动球；不多手/少指；不把球烙在人物层导致后续重复；不合并前景手与后景头发 |
| s030 | 角色 B、B-formal，依据 identity-v1；接稳后近景微笑，双手承重，按源近景保留头肩；表情变化仍是同一人 | 不放大头部挤出窗口；不漏配饰；不以几何头替代发丝脸眼；不把文字绘入人物层 |

生成前附当前镜头构图图、角色视角参考、必要动作关键帧；避免把整段聊天塞成提示词。
生成后实际查看结果；文字声称“完全一致”不构成身份或动作证据。

## 抛、飞、接、承重的检查

示例 s020 全局 `[60,120)`；节拍与事件对齐：

| 事件 | local / global | 可观察关系 |
| --- | --- | --- |
| 蓄力 | 0 / 60 | 肩肘腕形成发力姿态，球由手支撑 |
| 释放 | 12 / 72 | 手腕/手指变化，最后接触点与离手方向一致 |
| 飞行顶点 | 24 / 84 | 球独立飞行，手与身体按参考继续动作 |
| 首次接触 | 42 / 102 | B 手球位置贴合，手指和球的前后层合理 |
| 接稳承重 | 54 / 114 | 手腕、肘和肩响应重量，球不漂浮或穿手 |

对照肩→肘→腕→掌→指→球，而非只对齐球心。
投掷前球随手，离手后解绑定，接触后再绑定接球手；握持听筒、杯子等也应绘制匹配的手姿。
关键接触前后短段必要时逐帧查看；像素误差低不能证明物理关系合理。

## 局部换头与比例保护

仅修头部时复用已通过的躯干、手和道具，保留它们的动画与像素关系。
先测正侧脸、睁闭眼、抬手遮脸、最近/最远镜头和最大位置变化。
使用实际替换头部 mask 检查 mask 外像素；固定高度线可能切进新头，无法证明身体未变。
手球在头前方时重新覆盖前景手球层，不把头贴到它们之上。
比较同角色相近尺度的头肩比例，取完整头/颈/肩/半身，不只看眼睛或头部特写裁片。
