# 生产、返修与最终验收

## P3-A：代表动态样片先于全批量

从真实分镜选能暴露风险的镜头，不只选最好画的静态正脸。
样片至少覆盖本项目最难的动作、角色视角、接触/遮挡、文字与适用的转场。
先完成必要姿态和最小单镜头编排，再实际导出；静态测试图不等于动作方法已通过。
分别判断：静态生成能力、参考编辑能力、关键姿态连接能力、分层合成能力。
局部修图/补姿态/分层运动仍不能完成重要动作时，列明受阻镜头及所需人工或外部素材。
不要用整张静态图平移或额外光效掩饰动作缺失。

样片记录应回答：

- 角色身份与画风是否同时成立；转身/闭眼/近景是否仍是同一人？
- 肩肘腕手与道具是否呈现动作；接触前后是否正确？
- alpha 主体像素、头肩比例及窗口取景是否足够？
- 字幕/设计文字、原布局和节奏是否保留？
- 单镜头与全片相同全局帧是否一致，转场上下文是否完整？
- 已获授权能否继续批量；用户约定的审核/暂停点是否到达？

有授权就继续；缺关键决策才确认。不把技术检查或代理自审伪装成用户批准。

## P3-B：冻结镜头与复用

按镜头记录输入版本、角色/服装、姿态序列、图层顺序、文本 cue、生成参数、实际查看的证据及结论。
通过后计算真实内容哈希，冻结引用；重复姿态可复用，别重新生成“差不多”的角色。
母版变更时列出引用它的镜头，避免只修当前图而全片仍混用不同身份。
失败或中断输出单独命名，不能沿用正式文件名冒充成功成片。

## 匿名返工经验：症状到复核点

下表是可迁移的失败类型，不是新项目默认要出现的内容，也不含原始素材。

| 症状 | 原因 | 正确修法 | 复核点 |
| --- | --- | --- | --- |
| 多出旧手、旧衣边 | 新人物直接盖在未清理原人物上，补丁范围不足 | 更新 clean plate/真实人物遮罩，保住旁边道具 | 补丁首中末与轮廓外，数清可见肢体 |
| 手与听筒/杯柄分离 | 只平移道具，没有匹配握持姿态 | 连同手指、掌、腕和道具接触关系一起绘制/定位 | 指尖包覆、接触点、线缆连续与前后遮挡 |
| 两角色忽大忽小 | 透明留白/裁片大小当作人物大小 | 用 alpha 主体、头高肩宽与场景基线比较 | 同角色同尺度并排，双人相对身高 |
| 头顶动物/发冠只剩半个 | 素材本身缺失或错误裁切，反复挪位置无效 | 先修完整素材，必要时独立图层 | 单层全貌、合成后遮挡、头顶到边界 |
| 沙发双人、动物和枕头错位 | 各局部独立覆盖，没有共同构图底板 | 一起核对源布局，清理底板后按层重组 | 身体坐姿、背靠关系、枕头承托与动物遮挡 |
| 小窗切头/肩或只有脸 | 缩放锚点与窗口未共同核验 | 保留头肩/半身所需范围再按原镜头裁切 | 窗口首中末、近远景极值、完整头颈肩 |
| 文字穿人出现矩形硬边 | 金色文字与近色衣服被单一色阈值混成遮罩 | 用文字区域/真实文字层及局部遮挡分层 | 同色衣装不被误删，文字跨人物连续 |
| 球飞但手一直低垂 | 用移动球补静止手，缺真实投掷动作 | 重建肩肘腕手，按释放/飞行/接触/承重补姿态 | 关键事件和前后短段连续播放 |
| 头成灰椭圆、脸眼失真 | 把粗线风格误解成身份细节可省 | 恢复完整分缝、刘海、侧发、发丝、眼睛和脸型 | 正侧/眼态/近景，角色母版并排 |
| 修头后手球或躯干变了 | 重生整个画面或检查区域只用固定高度 | 只替换真实头部 mask，前景手球回盖，冻结通过的身体 | mask 外变化、手球 ROI、颈肩连续 |
| 全片背景轻微统一变色 | raw RGB/YUV 输入范围/矩阵不明，自动转换错误 | 明确输入约定，执行必要转换并匹配输出声明 | 源/最终未修改区域、肤色/灰色，不能只看标签 |
| 新片装入旧头或旧缓存 | 审批与文件名绑定，没绑定内容与依赖 | 更新 manifest/hash，撤销旧版本当前引用，保留回退 | 从实际最终 MP4 抽取代表帧与新资产核对 |
| 参数/对齐通过但动作仍假 | 技术指标被当作美术结论 | 分开报告文件、身份/画风与动作接触的证据 | 实际画面与连续播放，机器分数只作辅助 |
| 用户暂停后仍整理/渲染 | 将收尾流程放在停止指令之前 | 立即停自己的生成/编码，再简短报告状态 | 自有任务已停止，中断文件不冒充交付 |

## 评论映射到最小修改集

保留评论原意，按镜头/帧区间/元素映射，区分重复标记与不同问题。
明确本次必须修改、必要接缝与范围外发现；不把一轮标注扩成全片重画。
一个评论可能覆盖多段，一个镜头也可能有多个评论，不能用序号一对一强行绑定。

```json
{
  "requestId": "r010",
  "shotIds": ["s020"],
  "globalRange": {"startFrame": 60, "endFrameExclusive": 120},
  "issue": "释放到接稳的手球接触不连贯",
  "affectedAssets": ["A-release-v1", "B-catch-v1"],
  "preserve": ["identity-v2", "background", "text-cues"],
  "candidateVersion": "motion-v2",
  "evidenceFrames": [60, 72, 84, 102, 114, 119],
  "requiredSeamFrames": [59, 120],
  "status": "example-pending"
}
```

验收样张同时展示源参考、旧版、新版及完整上下文；放大图帮助查细节，全画面帮助查比例与布局。

## P5：实际最终文件检查矩阵

| 检查 | 最小覆盖 | 证据与判定 |
| --- | --- | --- |
| 参数 | 尺寸、fps 分数、帧数、时长、像素格式、音轨、颜色 | 与锁定 output/音频方案一致 |
| 完整性 | 最终文件从头到尾完整解码 | 命令、退出状态和错误日志 |
| 切镜 | 首次完整组装或全局时间轴变化检查全部边界/转场；局部返修检查受影响边界/接缝 | 未变部分可复用绑定原版本的审核，无意外黑帧/跳帧/漏帧 |
| 返修范围 | 每项首中末、不同关键姿态和必要接缝 | 评论实质解决，没有新增残留/矩形边 |
| 动作 | 释放/接触/承重与最大位置变化 | 手球相连、遮挡正确，不能只对齐轨迹 |
| 身份/比例 | 正侧背、眼态、最近/最远/最大头肩变化 | 与母版相同，完整取景，服装映射正确 |
| 音画/文字 | 起点、尾部、重音、字幕/设计文字边界 | 连续音轨偏移与 cue 一致 |
| 连续观感 | 首次完整组装或全局变化连续看全片；局部返修连续看修改段及必要上下文 | 未变画面可复用既有审核，披露本次实际播放范围 |

用实际最终文件，不以候选 PNG、缓存目录或旧报告替代：

```powershell
ffprobe -v error -count_frames -show_streams -show_format -of json "output/final.mp4"
ffmpeg -v error -xerror -i "output/final.mp4" -map 0:v:0 -map "0:a?" -f null -
ffmpeg -v error -i "output/final.mp4" -vf "select=eq(n\,72)" -frames:v 1 -fps_mode vfr "reviews/final-frame-0072.png"
```

先创建 `reviews/`；记录命令退出结果。probe 可统计帧，但不能代替全解码。
抽帧 PNG 也要检查显示/转换色彩约定；需要严格颜色对比时使用明确的解码转换链。
完整解码无错仍不能证明动作/身份通过；抽样通过不等于人工逐帧看过全部视频。
局部返修保留未变版本的既有验证，将本次修改帧、受影响边界/接缝与新成片绑定；每个最终文件仍完整解码。
首次组装或全局变化尚未完成全片连续播放时写明；局部返修也如实披露新片人工检查范围，不把局部首中末表述为本次已看全片。

## 版本绑定、失效传播与交付

验收记录示例，真实运行填写哈希和具体检查结果：

```json
{
  "artifact": "output/final.mp4",
  "artifactHash": null,
  "timelineVersion": "timeline-v1",
  "assetManifestVersion": "assets-v3",
  "technical": {"probe": "not-run", "fullDecode": "not-run"},
  "visual": {"reviewedFrames": [], "continuousPlayback": "not-done", "coverage": "none"},
  "requestIds": ["r010"],
  "unreviewed": ["example-record-only"],
  "decision": "example-pending"
}
```

已通过的候选可用于编码，不自动等于最终文件通过；绑定最终 MP4 哈希后才有确定交付对象。
逐帧机器对齐/PSNR/MAE应说明 ROI、压缩容差和谁实际计算/复核；低误差不证明美术正确。
角色/画风母版变更→复核所有引用镜头；局部修改→复核本段、相邻缝与成片。
时间轴/音轨/cue 变更→复核受影响同步点；输入替换→更新登记与依赖审核。
旧版保留但状态撤销为 superseded，不通过覆盖同名文件继承旧审批。

交付按约定提供：成片、实际参数/哈希、角色/画风依据、时间轴/分镜、资产版本、修改表与技术/美术记录。
不强迫每次交付所有中间文件；优先让用户能直接看成片和对应修改。
写清实际查看/播放范围、未检查项与已知限制；没有做的检查不能写通过。
到达用户约定的交付/审核点立即暂停，不新增“顺手精修”。
